# 首页2管理分析：实施与验收

更新：2026-10-15。首期阶段 A–D 已实现；以下分别记录实现、验证及限制。原首页及已有个人布局保留。

## 使用入口

- 本地：首页2 `http://localhost:5177/#/home2`。
- 点击「定制首页」，选择预置分析方案、「应用到草稿」，可先「预览布局」，点击底部「保存」后生效。应用方案和恢复模板都只修改草稿。
- 新增设备主管、公司与集团管理、仓库分析三套预置模板；初始化为未发布草稿、不绑定角色，不自动替换现有用户的首页。管理员可配置角色后发布。
- 工作布局约 2∶1，分析布局约 1∶1；支持主栏／侧栏、拖动、上下移动、个人配置及版本冲突保护。

## 已实现

### 阶段 A：公共能力

- 服务端指标目录；批量查询一次最多 12 个区块，统一统计截至时间。
- 页面周期、区块独立周期、公司／部门授权范围。排名前 5／10／20，同一种分析支持按区块 ID 添加多份。
- 公共 ECharts 图表，按需引入、尺寸观察、主题响应和销毁；使用明亮的蓝、青绿、紫、橙、粉、青色，稳定映射分类颜色。
- 统一分析明细页面，服务端分页、同口径导出、返回分析时保留查询上下文。
- 无数据、无权限、失败及缺失历史事实分别展示。金额、组织及来源仓库权限在服务端检查。
- 首页2角色配置与原首页独立，个人布局版本兼容；底部取消、恢复、保存固定。

### 阶段 B：维修、异常、人员

| 指标 ID | 内容 | 默认周期 |
| --- | --- | --- |
| repair_ranking | 设备报修次数排名 | 最近 90 天 |
| repair_trend | 报修与验收完成月度趋势 | 最近 12 个自然月 |
| fault_types | 故障类型分布 | 最近 90 天 |
| fault_causes | 故障原因分布 | 最近 90 天 |
| anomaly_ranking | 设备异常次数排名 | 最近 90 天 |
| personnel | 人员完成量、当前未完成、评分及样本、协同次数 | 最近 7 天 |

- 报修按报修时间，维修完成按最终验收通过事实；不把提交验收时间当完成时间。
- 已删、撤销报修与作废异常排除；打回重提不重复增加报修次数。
- 分类无法唯一映射的记录保留原文并进入未归类；分布超出前 N 项合并为「其他」，明细使用相同分组规则。
- 人员展示工作事实，不生成综合绩效分；当前未完成数标注截至当前。

### 阶段 C：保养、巡检

| 指标 ID | 内容 | 默认周期 |
| --- | --- | --- |
| maintenance_execution | 已生成保养任务执行情况 | 跟随页面 |
| maintenance_departments | 部门保养执行对比 | 跟随页面 |
| inspection_execution | 已生成点巡检任务执行情况，区分日常／周期 | 跟随页面 |

- 按计划日／计划执行时间归属周期；跨月补完成仍归原计划周期，展示当前结果及统计截至时间。
- 验收完成进度与按时提交率分开；打回使旧提交失效，验收等待不增加执行提交耗时。
- 人工作废排除分母；系统过期作废计入到期未完成。尚未到期且未提交的任务不进入及时性分母。
- 截止时间或有效事件缺失时明确展示，不能猜测及时性；无分母不显示虚构百分比。

### 阶段 D：物料成本与模板

| 指标 ID | 内容 | 默认周期 |
| --- | --- | --- |
| material_trend | 实际物料消耗月趋势 | 最近 12 个自然月 |
| equipment_material_ranking | 设备实际消耗金额排名 | 跟随页面 |
| material_ranking | 物料实际消耗金额排名 | 跟随页面 |

- 使用／安装事实只计算一次，已出库未使用不算消耗；换下不抹除原消费成本，不再次扣库存。
- 成本来自原分配，包含不含税成本和已分摊费用，按币种分开；最终使用／退料结清成本尾差。
- 单设备自动归属；多设备明确选择设备、拆分数量或登记公共用料。公共及历史未归属金额可核对。
- 新事实记录设备、公司、部门、操作人、金额及币种快照；缺失历史事实不补造。

## 已验证

### 隔离业务验收：55 项通过

测试数据库为 `eam_home_analytics_test_20261015`，使用正常认证测试配置验证权限，不依赖本地开发管理员绕过。

- 12 个指标查询；汇总／明细／导出一致；日期结束当天最后毫秒；分类其他组。
- 验收时间与提交时间区分；报修、异常排除规则；评分样本及协同分开。
- 4 月计划、5 月截止和验收的周期归属；打回重提、系统／人工作废、未来任务分母。
- 金额及跨公司权限、组织分析团队权限、指标白名单和批量上限。
- 使用幂等、安装单次消费、移除保留消费、自动／公共／拆分归属、不同币种分开。
- 10.00 成本分三次使用为 3.33＋3.33＋3.34；使用与安装不重复扣库存。
- MySQL 大整数 ID 精度、重复区块、个人版本冲突、独立角色发布及原首页保持。
