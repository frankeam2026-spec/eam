# 工程文档入口

仓库入口为根目录 `AGENTS.md`。规范以用户最新确认和根目录三份规范为准；本目录记录代码契约和实施证据，不另立UI或业务规则。

1. [UI交互与视觉规范](../../../UI交互与视觉规范-v1.2.md)：界面、控件、间距和交互。
2. [业务场景与领域规则](../../../业务场景与领域规则-v1.2.md)：流程、权限、数量和金额口径。
3. [前端组件与工程实施约定](../../../前端组件与工程实施约定-v1.2.md)：复用、依赖和工程约束；第12节为全系统数据库设计与存储强制约束（ENG-44至ENG-51）。
4. [前端架构](../../FRONTEND-ARCHITECTURE.md)：当前代码职责及公共契约。
5. [接口清单](API清单.md)：Controller入口、调用方、权限和版本契约。
6. [第一、二批实施记录](第一二批实施记录.md)：当前进度、验证及未完成事项。

日期化实施记录及 ENTERPRISE-QUALITY.md 中的旧记录属于历史证据，只适用于记录时的版本。它们不覆盖现行规范，也不能证明后续版本已经通过验收。

7. [设备台账导入使用与验收](../features/设备台账导入-使用与验收-20261018.md)：模板、批次、错误报告、安全提交及当前验证证据。

8. [多语言与语言包](../features/多语言与语言包.md)：账号语言、管理、公共国际化及接入约定。

9. [日常点检检查安排与验收](../features/日常点检检查安排-20261019.md)：检查安排、操作工责任、频次、人工事件及免检，本轮验证与未验证范围。
