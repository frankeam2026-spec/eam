# EAM UI 体验验收执行清单（轻量版）

> 本清单是执行工具，不替代根目录的 [UI 交互与视觉规范 v1.3](../../../UI交互与视觉规范-v1.3.md) 和 [UI 页面模板与验收清单](../../../UI页面模板与验收清单-v1.2.md)。本文件的场景是**待执行检查项**，不是已通过记录。

## 1. 每次 UI 改动怎么验收

1. **确认任务**：记录页面/路由、使用角色、主要操作、触发条件，以及影响的公共组件；注明此次改动涉及的现行 UI 规范编号。
2. **选择场景**：只验收改动影响的体验，不因小改动重测整个系统；跨页面公共组件至少覆盖一个典型页面与一个不同使用场景。
3. **实际运行**：打开当前代码对应的应用版本，核对 API 对接版本；至少在主要目标尺寸操作一遍核心任务，不用构建或截图替代交互。
4. **反例检查**：验证失败、空值、长内容、窄屏、重复操作、权限受限、未保存退出等与改动有关的情况。
5. **记录证据**：保留页面、环境、尺寸、角色、操作、预期/实际、截图或录屏位置、通过/失败/未验证；如无法打开页面，明确列出未验证项。

## 3. 体验检查项（按相关性选用）

- **布局**：优先核对 1920×1080 主布局、1280×720 兼容布局与 1024px CSS 视口宽度降级，并记录实际浏览器视口和缩放；内容不重叠；不会出现无意全页横向滚动；固定底栏不遮住控件或错误。
- **视觉**：变更涉及主题时核对蓝、深蓝、粉三种皮肤；品牌色与语义状态色区分；文字、图标、焦点和悬浮层清晰；复用现有设计令牌。
- **交互**：主次动作明确；加载、无数据、查询无结果、无权限、失败、冲突有可解释反馈；取消不暗中提交；重复点击不会产生错误状态。
- **数据一致**：筛选、分页、排序、导出显示口径一致；切换页面/返回时上下文恢复符合已确认规则；0、false、空值正确展示。
- **可访问性**：键盘可达、可见焦点、完整长内容可查看；图标按钮有可理解的名称；色彩不是唯一的信息表达。
- **真实性**：前端按钮隐藏不视作权限验证；真正涉及业务权限的用例还应通过安全的测试环境验证后端接口。
- **图形视觉**：图表、关系图、统计卡及业务图元按 UI-111～125 检查轻量分隔、少量稳定颜色、图例单位、长标签、关键数值、三种皮肤与可访问性；不为了美化增加不必要的卡片或业务功能。
- **图表到业务**：使用代表数据核对图表与明细一致，选中／返回上下文准确，不把当前分页当全部统计；无数据、未知、错误与权限受限状态独立显示。
- **多语言及长任务**：受影响页面按 UI-126～128 检查简繁英长文案、过程进度、失败重试和帮助入口；仅在本次变更涉及时执行。
