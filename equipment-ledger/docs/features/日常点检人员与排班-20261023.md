# 日常点检人员与排班

用户确认：人员安排属于检查安排；班次只定义一次。支持现场直接点检、指定人员、班组成员、按排班。现场模式到点生成无实际执行人的任务，扫码或选择设备只查询任务，开始时原子确定执行人。排班支持常规规则、星期规则和日期例外及周月批量维护。

## 实施前数据设计审查

- 保留现有计划、检查安排、班次时段、任务、执行、人员关系及审计表。现场模式使用安排 person_mode=open，任务 person_mode=现场直接点检，不把所有租户人员复制为候选。
- 新增常规排班表 `eam_inspection_daily_staff_rule`：租户、安排、规则键、星期（0表示每天）、班次键、覆盖开始及结束时间、明确无人标记。规则人员使用独立关联表。
- 新增日期例外表 `eam_inspection_daily_staff_override`：租户、安排、例外键、业务日期、班次键、覆盖时间、明确无人标记。例外人员使用独立关联表。
- 班次或多时段引用安排已有 slot_key；普通日期使用空 slot_key，固定间隔及人工事件可配置人员覆盖时间，跨夜按覆盖开始日期解析。相同优先级重叠规则拒绝保存。
- 两种表分别承载周期规则和具体日期调整，日期、时间、状态均为明确列，人员保存真实用户ID；不用JSON承载核心排班。唯一键防重复，外键关联安排和人员，按租户／安排／日期查询。
- 旧计划级排班按原 shift_key 匹配安排已有班次回填日期例外，同日同班多行合并人员。保留旧表用于回退核查，不删除无法匹配的原记录。新界面保存前要求处理失效关联。
- 保存沿用计划行锁、版本、关联ID及权限校验；安排修改不重写已执行历史。未开始任务重新解析人员必须在同一计划事务中锁定并记录变更，显式转派任务不被常规刷新覆盖。
- 现有任务的历史项目快照和视图JSON组装仍是既有兼容边界；本次新增排班只以关系表为来源，不宣称已重构整个执行快照模型。

## 匹配及执行边界

设备人员例外优先；其后按指定日期、指定星期、每日常规匹配。明确无人记录阻止向低优先级回退；缺排班不转为开放、不免检、不减少任务。现场模式不强制跟进人，已设置的跟进人必须有效。

本次不包含自动循环轮班、多人各自提交或移动端离线协议。后续验证结果在本文件补充，历史通过记录不作为本轮结果。

## 已实现与使用入口

- 检查安排提供 open／specified／team／roster 四种方式；已有安排不自动改为开放。新安排默认现场直接点检，可不指定跟进人。
- 常规规则复用已有班次，提供一键填入班次行；星期规则覆盖每日规则。按日、多时段、固定间隔、人工事件均可使用安排级排班。非班次检查不强制创建虚构班次；间隔与事件按人员覆盖窗口匹配。
- 日期调整提供周／月视图、勾选日期、范围与星期批量填充、仅填空白或显式覆盖、复制上周及撤销。明确无人会阻止向常规规则回退。跨日期和周边界的重叠人员覆盖窗口拒绝保存。
- 保存前预览影响的未开始任务数量；同一事务锁定计划与任务后刷新候选及跟进人、增加版本并记录事件。已开始、提交、完成或显式转派的任务不改写。
- 已有当前／未来未开始任务时，修改检查频次或班次时间会要求先处理这些任务，避免新旧时间重复生成。修改人员排班不受此限制。
- 日常点检任务工具栏及设备概览均有“设备点检”入口；扫码枪输入设备编号或通过分页选择器选择设备后查询任务。查询不新增任务；开始时沿用任务行锁、版本校验、库存互斥锁顺序和事务，记录实际执行人及事件。
- 人工事件时间规范到数据库秒级精度，同一请求重试保持幂等。提交记录保存实际提交用户。
- 实际页面核对中修复原有无指令 template 导致计划有效期、启用及验收字段未显示的问题，并补齐组件导入和局部显示容器。

## 本地升级与回退边界

升级前备份位于 `.local-runtime/backups/eam_local_dev_before_staffing_20261023.sql`。本地 eam_local_dev 从V92升级到V93成功；原排班0条、新日期排班0条，与来源匹配计数一致；非空回填由隔离样本验证。用户业务数据没有用于测试执行。

回退不得直接删除新排班表；旧程序无法理解 open 模式。需先核对升级后业务写入和新模式使用情况，再选择兼容版本或经过核对的数据库恢复，不能盲目覆盖后续业务数据。

已知历史问题：重放空库迁移时，V25／V26的 MAX(id)+序号 与 V61的 UUID_SHORT 混用可能导致权限编号冲突。本轮未修改已执行脚本；隔离升级样本在V60后预留中间编号再完成V92基线，单独验证V93升级，不能据此宣称历史空库迁移问题已解决。

未验证：真实扫码枪／PDA硬件、长时间调度稳定性、大规模排班性能、移动端离线以及完整库存业务链；本轮不以构建结果代替这些验收。
