# 小卓统一业务查询实施记录

日期：2026-10-29。范围依据：[查询优化与场景矩阵](../plans/小卓全业务查询优化-20261029.md)。该矩阵包含已实现能力与尚有数据缺口的场景，不能视为全部场景已经验收。

## 已实现

| 查询对象 | 本轮能力 | 明确边界 |
| --- | --- | --- |
| 设备台账 | 数量、清单、分类/公司/部门/状态/品牌分组、记录占比、排行、创建/购置日期筛选 | 不推算运行小时、故障率、OEE |
| 维修 | 状态/设备/部门/人员/故障类型原因筛选分组，报修/接单/提交/验收时间，趋势 | 工单数不等于独立故障次数，不计算未经核实的维修时长或完整成本 |
| 保养 | 计划启停、任务状态/设备/负责人/计划日期筛选、分组与趋势 | 计划公司直接筛选、标准项目与触发原因未纳入统一目录 |
| 日常点检/周期巡检 | 计划启停、任务时间/状态/班次/设备/部门、项目异常等计数和聚合 | 负责人不能冒充实际点检人；项目明细追溯未纳入统一目录 |
| 库存 | 现存/预留/可用数量、仓库/公司/物料/批次/单位筛选、分组汇总 | 不跨单位求和；不返回成本，不推测安全库存或呆滞阈值 |
| 本人事项 | 指定审批/验收/接单类型的个人事项查询、分页、进入原业务页面 | 不把所有待办冒充待审批；不代人操作 |
| 管理概览 | 最多6组授权查询，分别标明范围与时间，可并列展示不同业务 | 不编造同比环比、因果、损失、预算或投资回报 |

已有指标如完成率/按期率及实际用料金额仍走既有HomeAnalyticsService与权限，不使用另一套计算公式。自然语言可拆为多组查询；未支持的条件明确说明，不静默丢弃。

查询计划采用有界条件树，支持AND/OR/NOT、文本/日期/数值/空值筛选。后端注册字段与SQL表达式，模型不生成SQL。按稳定ID分组，同名对象等值筛选发现歧义时要求补充限定。

对话内追问传递上轮校验后的查询结构，后台再次校验，查询权限每次重新取得。本轮新写历史只保存“重新查询”提示，不持久化可能在权限变化后失效的业务数值或结果行。分组、趋势和数量可穿透明细，分页20/50/100；点击编号进入现有详情。

## 数据与工程核对

本轮没有数据库结构变更或新增迁移；开发库与隔离库保持V115，不改动业务快照，不将业务数据批量写入向量库。已有JSON视图和任务快照的存储讨论不在本轮整改范围。

Controller校验协议，Service鉴权与业务编排，Repository执行SQL。使用既有业务权限构建授权数据源；公共层仅在该数据源内查询。结果由后端格式化，不把列表和统计数回传云端模型。模型仅收到问题、字段目录、最多3条最近问题、上轮查询结构、本人待办类型元数据，以及明确提及“本公司”时所需的当前公司归属元数据。未指定公司时不附加当前公司筛选；不接受模型猜测关联ID。

单条SQL限制执行时间8秒，数据库内计数/聚合/分页；输出Token上限2400，本次规划2200，按实际请求上限预占预算。未更改用户预算和模型价格。
