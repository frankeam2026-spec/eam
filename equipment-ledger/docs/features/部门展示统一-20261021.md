# 部门展示统一（2026-10-21）

## 实现

依据UI-110，默认显示末级部门，悬浮或键盘聚焦显示以“ > ”连接的完整路径。公共DepartmentText处理单个部门，DepartmentValuesText处理多个部门；兼容旧间隔点，保留英文句点。

接入设备台账、档案及历史、维修、保养、点巡检、用户管理、账号与个人设置、组织详情、领用出库、标签打印设备选择、公共人员／设备选择及自定义部门字段。树选择控件保持末级选中标签，悬浮显示完整路径。自定义字段部门候选接口的路径拼接同步改为“ > ”。

部门ID与筛选值不变；公共TreeSelect与筛选树保留旧文本查询值，仅改变其路径标签。已有完整历史快照优先使用原路径。只有名称的记录，在当前账号可见部门中唯一匹配时补全路径；重名或无匹配时保留原名，不猜测历史归属。部门数据复用原授权组织接口，按租户与账号缓存一次；切换账号清空，旧请求不能覆盖新账号。组织管理刷新后同步更新展示缓存。

## 验证边界

新增回归覆盖旧分隔符兼容、ID与旧查询值保留、末级展示及全路径提示、历史快照、同名歧义、账号切换后的迟到请求，以及自定义多部门不丢失身份。后端BusinessReferencePathTest使用模拟依赖验证候选路径与ID，不连接业务数据库。

未验证：全部页面、皮肤和语言组合的人工验收，以及大规模组织性能。未做数据库结构或数据迁移，没有向开发业务库写入验收数据。无法唯一定位的历史文本不能保证恢复完整路径。
