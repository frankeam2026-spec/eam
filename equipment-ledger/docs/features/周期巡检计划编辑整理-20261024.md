# 周期巡检计划编辑整理

## 实施前审查
范围为周期巡检计划编辑及首次调度。巡检类型仅提供默认周期，计划可单独修改数值/单位，使用计划自身周期生成任务，不修改类型或其他计划。计划有效期现为DATE，首次取开始日期00:00，不新增独立开始时刻。

复用`eam_inspection_periodic_plan.start_date`、`period_count/period_unit`和独立调度表`eam_inspection_schedule.next_at/anchor_at/cycle_index`。计划表旧next_at列及DTO nextAt保留兼容，但旧客户端输入不再决定首次起点；列表nextAt继续由实际调度游标计算。无新表、JSON或关联关系。

V100只对从未生成任务的计划（含已软删除任务也算生成过）按计划开始日期归一首次锚点；受影响计划行版本加1，已有任务的历史锚点及调度进度不改。普通保存不再拿已推进的游标与首检日期比较并重置。修改开始日期/类型/周期仍使用既有版本及已生成任务范围校验，禁止重置覆盖已存在任务的时间段。

读写方：InspectionService保存、InspectionGenerationService生成、InspectionViewAssembler详情及InspectionListRepository列表、InspectionModule表单。迁移前备份，核对历史任务数量、调度关联和无任务计划的锚点；回退需恢复旧锚点及游标，不根据当前游标猜测过去首检时间。

## 巡检周期允许计划级修改（用户补充）
巡检类型仅带出默认值，计划的数值及日/周/月/年单位可单独编辑。后端仅在参数缺省时使用类型默认值，显式参数校验整数1至10000及有效单位后保存到既有独立列；不覆盖字典和其他计划。页面手动修改周期时沿用原选择类型时的任务有效期默认同步方式；已有任务的周期修改仍保留原冲突校验，不重写已有任务。
