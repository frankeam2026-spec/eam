# 日常点检计划界面简化

2026-10-21。用户确认简化日常点检计划配置；参考方案仅作参考，保留现有业务模型。本次只调整日常计划界面及对应语言文案，不修改后端业务、数据库或任务生成规则。

## 页面变化

- 设备和检查项目合并到“检查什么”，减少配置页签；“时间与人员”展示检查安排，“特殊日历”保留休息及特殊开工日配置。
- 检查安排由多层页签改为汇总表，展示范围、时间和执行人员，点击编辑展开一项安排。
- 编辑中同步显示规则摘要，包括重复周期、指定星期、班次、跨夜截止时间、事件完成窗口及人员；单独展示起算日及逾期设置。
- 部分设备／项目范围和起算日期／逾期规则按需展开；设备操作工例外保留、显示优先级提示，汇总标明适用设备例外数量。
- 指定执行人员与跟进负责人区分说明。宽屏安排表单三列，1400px以下两列、900px以下一列。
- 现有设备行操作工例外自动显示，未设置时可主动打开；保留设备验收人配置。使用排班的安排下方继续维护排班。
- 收起编辑只折叠界面，不撤销输入；页面底部统一保存。服务端安排字段报错自动打开对应安排与折叠区域，设备字段报错返回“检查什么”。

## 验证与边界

- 新增三个安排组件交互测试：汇总跨夜和重复规则；编辑收起后保留输入及设备人员例外；字段报错定位正确安排。
- 连同标准字段校验及检查项目表头回归，共7项测试通过；类型检查和生产构建通过。
