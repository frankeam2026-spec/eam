# 多语言与语言包

## 用户使用

个人设置 → 显示语言，选择后自动保存当前账号并即时切换。内置简体中文、繁體中文、English；登录页也可以选择语言。语言与主题分别保存。切换不刷新页面，不改变业务状态、字段值或权限。

部门、设备、基础数据、自定义字段及客户填写内容保留原文。自定义字段所在分区的“扩展信息”和校验提示会翻译。历史纯文本通知保留原文，新通知保存消息键及参数，在查看时翻译。

## 管理员使用

系统管理 → 语言管理。一个菜单权限“查看”允许维护。系统管理员默认拥有，其他角色需管理员授权。普通用户读取公开的翻译资源不需要管理权限。

1. 下载 JSON 模板，使用 UTF-8 编辑。只改译文，不改稳定词条键或命名占位参数。
2. 导入后先查看新增、修改、缺失、未知和无效项。无效项必须处理；未知键会忽略。
3. 确认后整体保存。新语言默认停用，检查后点击启用；内置语言不可停用。
4. 缺失项回退简体中文。导出可继续维护；内置译文可覆盖和恢复。
5. 管理员更新即时刷新当前窗口；其他打开窗口重新聚焦或最多约一分钟后检查语言包版本。离线时保留已加载语言。

见 [法语部分翻译示例](../../examples/languages/fr-FR.json)。该示例有意只翻译部分内容，用于检查中文回退；生产语言包还应填写组件和日历词条。

## 格式及限制

```json
{
  "formatVersion": 1,
  "locale": "fr-FR",
  "nativeName": "Français",
  "direction": "ltr",
  "messages": {
    "language.field.displayLanguage": "Langue d’affichage"
  }
}
```

messages 使用稳定模块前缀的平铺键。2MB、最多30000条、每条最多6000字符。占位参数如 `{p0}` 必须与模板一致。只接受纯文本，禁止 HTML、脚本、外部资源执行、原型污染键和消息链接语法。首期只支持从左到右布局。

`component.*` 是 Element Plus 原生语言文字，保留其 `{total}`、`{pager}` 等参数，由组件插值；`calendar.*` 用 `|` 分隔月份/星期，保留12个月和7个星期的顺序。数量和金额仍为两位小数，时间采用现有系统时区，导入日期仍采用 YYYY-MM-DD。

## 开发接入

- 系统文案使用 `tr(稳定键, 参数)`；只翻译显示，不翻译请求值、状态存值、权限动作和 ID。
- 词条源为 `src/i18n/source.json`，英文术语优先取 `scripts/i18n/terminology-en.json`，其余维护源为 `scripts/i18n/en-draft.json`。内置繁体由 OpenCC 构建生成，组件语言取 Element Plus 官方包。
- 执行 `node scripts/i18n/build-catalog.mjs` 同步前端与后端资源。新增词条必须进入三种语言并保留同一组参数。`npm run check:i18n` 检查键一致、消息语法、参数和 Vue 静态中文文案。
- 后端业务错误使用 `LocalizedArgumentException` / `LocalizedStatusException` / `MessageRef`，字段错误保留字段路径。Controller 仍输出 code、message、fieldErrors。
- MessageContext 为请求/工作线程持有的只读快照。异步任务显式传递并关闭作用域，不能继承其他用户的语言。
- 语言读取：合法启用的 Accept-Language → 账号偏好 → zh-CN。公开资源不包含业务数据、用户信息或管理日志。
- Controller → Service → Repository；语言包确认、覆盖替换和操作日志在同一事务提交。SQL 只在 Repository。

## 数据与兼容

V85 新增账号 locale、语言元数据、覆盖词条和管理日志；V86 为新通知增加消息键与参数；V87 增加词条模块列与索引。迁移不改写核心业务、库存和已留底打印内容。

内置包随程序发布，客户包是数据库覆盖层。服务端按租户、语言和版本缓存；公开资源支持 ETag。语言停用后账号原偏好仍保留，临时使用简体中文。
