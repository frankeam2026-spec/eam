# 工作流编辑体验优化与验证

## 范围与参考

依据用户确认的编辑体验方案，参考Camunda Modeler的属性分组与问题定位、芋道和Warm-Flow的业务审批配置思路。保留现有Flowable、bpmn-js和关系模型，不引入另一套流程引擎或双设计器。

## 已实现

- 编辑时临时收起导航，返回后恢复原导航状态，不更改个人导航偏好。顶部显示模板、公司、基本信息、配置检查、版本和试算；依照UI-47，保存与发布保留公共底部居中操作栏。
- 已有模板默认收起基本信息，节点属性按基本设置、审批设置、执行路径及脚本计算分组。说明复用公共提示组件；字段标签继续左置。
- 审批节点显示已解析的人员/角色和通过方式；选择较多时摘要展示，悬停查看完整摘要。条件线显示业务变量名称，核心表达式和BPMN导出中的原始名称保持不变。
- 节点旁加号可新增审批或条件分支，自动接入原后续节点；保留手动连接与节点工具栏。图标复用公共IconPark映射。
- 预检查聚合审批人缺失、无效连接、断开节点、循环、子流程边界、脚本输出变量及服务端条件解析问题；点击可定位节点和属性分组。该预检查不替代发布时的后台完整校验和权限检查。
- 试算分为输入数据、执行路径和计算结果。审批明确标注模拟通过，点击路径可返回画布定位，不将试算当作真实审批。
- 领料审批每轮增加只读流程进度图和人员/时间/意见明细；颜色依据已有审批记录与节点事件，未执行子流程不伪装为已完成。进度数据取该实例固定版本，仅返回拓扑，移除脚本、条件表达式和人员/角色配置；不通过开放模板管理权限实现业务查看。
- 修正BPMN导入及画布编辑时，父组件数据尚未同步就回写旧配置的时序问题。导入在同步保护内整体接收，失败恢复原图与模型；正常编辑在下一次Vue更新后序列化。
- 工作流页面使用视口高度约束，画布和属性面板分开滚动，窄窗口底部按钮保持可见。

## 分支增删与连线修复（2026-10-27后续）

用户反馈在开始节点新增分支后图形错位、删除两个后新增一个却出现三个，以及连线重合难以拖动。本轮复现并修正：

- 画布节点和连线创建时，必须通过bpmnFactory显式指定业务对象ID；仅给视觉元素设置ID会产生不同的语义ID，导致后续读取、重建和删除不同步。
- 自动排版的整个过程暂停业务模型回写，结束后保存布局；读取waypoint时排除标签元素，不将标签误认为零坐标点。节点外部标签与连线标签独立安排位置，使用bpmn-js的尺寸和移动命令保留撤销及DI同步，不改写业务条件文本。
- 同一源、目标的多条流程线分开安排路径，避免条件和默认路径完全重合；连线文字在布局时避开节点和其他已放置标签。复杂人工连线仍支持选择蓝色手柄调整，不在每次手动拖动后重新自动排版。
- 删除网关时优先接回默认路径（单路径使用该路径），不直接把原后续节点全部绕到结束。其他分支节点保留，失去连接的节点由配置检查报告，不擅自级联删除。
- 标签点击按labelTarget选择真实节点。

实际页面按以下顺序验证：开始处新增第二个网关；删除两个后标签计数为0；再新增一次计数为1；默认路径选中后出现蓝色调整手柄，水平段拖动后waypoint的y由140变为190，位置保留。全部操作仅在独立验证页暂存，没有保存或发布模板。截图.local-runtime/workflow-branch-fix-20261027.png。

新增回归包括：真实bpmnFactory的节点/连线ID、连续网关的执行顺序及双路径不同轨迹、标签不作为waypoint、文字避让节点与标签。完整本轮前端回归16项，日志workflow-branch-tests.log；类型及构建日志分别为workflow-branch-typecheck.log和workflow-branch-build.log。无数据库或后端改动；复杂多层流程的所有交叉组合未进行穷举人工验收。
