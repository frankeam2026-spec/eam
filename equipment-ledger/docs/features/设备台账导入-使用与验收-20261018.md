# 设备台账导入：使用说明与当前验收

实施日期：2026-10-18；最终验证日期：2026-10-19。本记录只适用于本次提交的版本，不替代后续业务验收。

## 使用方法

1. 在设备台账点击“导入”，在当前列表上打开弹窗。需要同时具有设备的导入、新增权限。弹窗主体内部滚动，底部操作靠右；遮罩及Escape不关闭。批次号保留在URL，刷新可恢复。
2. 点击“下载导入模板”。工作簿包含设备数据、填写说明、可选数据三个工作表。
3. 从设备数据第3行开始填写。隐藏的第一行保存字段标识及扩展字段版本，不要删除；示例位于填写说明，不会导入。
4. 上传不超过10MB的 `.xlsx`，最多10000条。上传仅校验，不生成设备或占用编号。
5. 默认查看错误行。错误单元格及右侧说明标明Excel行号、字段、原值、原因、修改建议；可切换全部数据和全部字段。
6. 下载校验结果，在原数据上修改；辅助错误列会被忽略，修改后的结果文件可直接重新上传。
7. 全部通过后点击“确认导入”。后台重新校验并在一个事务中提交，任一失败整批回滚。
8. 成功后查看本次设备；URL保留批次号，刷新可继续查结果。相同批次、相同确认请求不会再次新增。

## 填写规则

- 仅新增，不覆盖已有设备；设备编号可留空，由原编号规则生成。填写编号时按MySQL实际大小写及重音排序规则检查重复。
- 所属部门和位置填写完整路径，分隔符为 ` > `；旧模板的 ` · ` 仍可匹配。类别保持原有路径规则。公司由部门带出；位置须属于该公司。可选数据另列位置所属公司，避免混用。
- 单位、使用状态、设备来源填写可选数据中的有效名称。不猜测同名对象，不自动创建基础数据。
- 负责人填写登录账号，多人用中文分号 `；` 分隔；正式关联保存人员ID。
- 父设备编号支持同文件或已有设备。要求同公司、单父设备、不自关联、不循环，并具备对应设备的查看和编辑权限；追加到已有父设备不会覆盖其原子设备。
- 日期填 `YYYY-MM-DD`；扩展日期时间填 `YYYY-MM-DD HH:mm:ss`。购置金额最多16位整数、2位小数。
- 设备状态、使用状态等核心必填项必须填写。可选的是非空白按原新建设备的“否”处理。
- 发布的扩展字段随模板追加。是非填写“是／否”，选项填写显示名称，用户填写账号，部门填写全路径，多值用 `；` 分隔；数值0和是非“否”不是空值。
- 隐藏扩展字段不得填写非空值，默认值与显隐、必填使用原动态字段规则。字段配置改变后必须下载最新模板重新校验。
- 不执行公式，请将公式结果粘贴为值。文本编号会保留前导零。
- 首期不导入图片、附件、设备BOM，不提供列映射、旧记录覆盖或部分成功。

## 工程实现与存储

- 通用批次、列目录、原始输入单元格、逐字段错误，和设备专用暂存行／负责人、成功设备关联分别建表。正式设备、负责人及扩展值仍写原业务表；没有新增核心payload列。
- `V82`建立批次和暂存表；`V83`持久化确认请求版本及幂等键唯一约束；`V84`扩展暂存的部门／类别路径长度。均为新增迁移。
- 原Excel私有保存于配置上传目录的 `private-imports/` 子目录；没有公开静态文件入口，报告需批次本人鉴权。
- 文件、错误及暂存行7天后定时清理；批次摘要和成功设备ID关联保留。清理会锁批次并避开正在处理的批次。
- 单体进程中两个有界后台执行线程，最多排队8批。满载明确告知稍后重试。重启中断的未完成批次标记失败；设备、关系、扩展值及成功状态在同一事务，避免半批数据。
- 当前为单实例本地文件存储；多实例部署前需改为共享私有存储及有租约的跨实例任务调度。本次不声称支持多实例任务恢复。
- 模板／报告先完成鉴权和生成，再设置Excel响应头，权限和文件错误仍以标准JSON返回。
- 原有公司锁及库存互斥顺序保留；确认期间共享锁保护关联基础数据、组织和用户，业务字段配置按原规则加锁。批量校验不逐行查询字典或人员。
- Excel采用Apache POI 5.5.1，SAX读取、流式写入，限制压缩文件、展开尺寸、列数、单元格数和文本长度。依赖来源：[Apache POI官方发布说明](https://poi.apache.org/download.cgi)。
