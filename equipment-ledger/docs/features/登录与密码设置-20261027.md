# 登录与密码设置（2026-10-27）

依据：用户要求登录页增加记住密码，登录后进入首页，密码至少6位。

## 已实现

- 登录成功后先导航至首页，再加载基础数据；仍由路由和后台校验权限。
- 登录页增加 Element Plus 记住密码选项，仅在登录成功后记录租户、账号与选项；密码交给浏览器密码管理器，不写入 localStorage。取消勾选清除账号记忆；浏览器已保存的凭据需在浏览器自身设置中管理。
- 不支持 Credential Management 的浏览器沿用原生 autocomplete；保存和填充受浏览器支持及用户设置控制，不宣称各浏览器都能自动保存。
- 用户新增、编辑、批量重置、个人改密、管理员初始化的最低密码长度由12位改为6位，同步三种语言；没有修改现有用户的密码。

## 验证

- 3项前端测试：密码不进入本地偏好存储、取消记忆、浏览器拒绝或偏好损坏时不影响登录。
- 2项后端测试：6位密码可修改并撤销旧会话，5位密码拒绝且不写入。
- 实际页面从 /workflows 登录后进入 /home，记住密码选项及提示正常显示。
- 前端类型检查、语言目录校验和后端打包通过。
- 未验证：各种浏览器密码管理器的真实保存／重新填充行为；未修改任何现有业务数据或用户密码。
