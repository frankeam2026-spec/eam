# 高级工作流实施记录

用户授权完整BPMN编辑器及脚本能力，当前实施并行/包容分支、嵌入子流程、脚本节点，继续兼容已发布版本。不得以画布支持替代真实执行或宣称BPMN全部构造已验收。

## 实施前数据与调用方审查（ENG-44至ENG-51）

- `wf_node.parent_key` varchar50可空：嵌入子流程容器，同一版本内校验真实父节点与边界；按版本读取，版本/parent_key索引。父节点必须SUBPROCESS，不接受跨容器连线。
- `wf_node_script`：tenant/node复合主键并外键关联节点；language varchar16、source_code TEXT（限制32000字符）、output_key varchar80、output_type varchar16；仅脚本定义，不承载业务关系。输出不可覆盖业务变量。
- `wf_branch`继续表示网关出边：互斥/包容保存条件关系，并行边无条件、无默认边，不保存伪条件。普通后继仍使用next_key，不将核心连接塞入XML。
- `wf_approval`唯一约束调整为租户/实例/引擎任务/用户，按真实引擎任务精确完成和取消，防止并行或重复到达同名节点互相关闭；历史数据保留。
- 脚本输出仍写入`wf_value`明确类型列；新增`wf_script_run`记录实例/节点/执行ID、源码SHA256、执行起止、输出类型及类型化输出，索引租户/实例/开始时间。失败随业务事务回滚，向调用方返回错误。输出不写通用JSON；传给隔离进程的临时JSON仅为IPC，不代替业务存储。
- 新增V107；现有102至106不改写。发布/保存检查关联ID、租户、公司、版本及脚本专用权限。模板、审批、领料锁顺序及原库存入口不变。

## 执行边界

Flowable接管并行及子流程token，业务审批候选绑定真实活动任务。网关在进入节点时读取关系条件与提交快照/已计算输出。进程仍存在但暂时无用户任务时，不可误判审批通过。

JavaScript运行于独立JVM，关闭Java宿主访问、IO、网络、进程创建和线程创建；子进程清空业务凭据环境，限制堆、输出、并发和总时限，超时销毁。只执行计算并返回一个声明的NUMBER/TEXT/BOOLEAN值，不能直接更改业务表。提供精确十进制字符串运算辅助，金额来源仍不擅自接通。发布、配置及试算为独立权限。

## 验证

### 已实现

- 开始、审批、结束、互斥网关、并行网关、包容网关、嵌入子流程及JavaScript计算节点；网关到达时读取当前快照和计算结果。审批按实际引擎任务关联，同一人同时办理多个并行节点时可选择节点，意见分别保留。
- BPMN画布拖放、连线、属性配置、撤销重做、缩放、自适应、自动排版、导入导出；导出包含审批人、角色、条件、脚本和子流程内容，折叠子流程不会丢失内部节点。XML是布局与交换产物，后台仍从校验后的关系模型生成可执行流程。
- CodeMirror脚本编辑、输入样例、单脚本试算、真实Flowable整流程试算。整流程试算在独立回滚事务中执行，不创建业务审批或通知。
- JavaScript每次执行最多8秒，单次流程推进的脚本总预算15秒，整流程试算预算20秒；最多2个脚本并发，独立进程堆128MB。NUMBER必须返回十进制字符串，提供decimal工具避免二进制浮点误差。
- 新发布版本标记execution_version=2；已有版本保留原路由兼容路径，不重写历史定义。
