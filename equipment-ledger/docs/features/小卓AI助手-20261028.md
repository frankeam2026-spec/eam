# 小卓AI助手实施与验收

日期：2026-10-28。本文件记录当前实现；早期《小卓知识库存储设计》中的分阶段状态不再代表当前交付状态。

## 已实现的入口与业务能力

- 登录后具备知识库查看权限的页面显示小卓浮动入口，位置按租户和账号分别保存。可拖动贴边、收起、放大。按2026-10-29用户确认，桌面打开440px宽、最大600px高的右下角悬浮聊天窗，不改变业务页面宽度，背景可继续操作；放大或600px及以下小屏使用全屏并隔离背景焦点。换账号卸载对话组件。
- 个人会话在服务端保存，列表数据库分页20/50/100；问答按50轮分批读取，可加载更早消息。请求键防重复计费；失败与结果未知区分处理。跟进问题参考最近3条有效用户问题，不把旧模型回答当作事实。
- 对话可指定设备，更换设备创建新会话；未指定时只查所属授权公司内显式标记的通用资料，指定设备后只查该公司通用资料及该设备关联资料。
- 知识库管理支持设备手册/SOP PDF上传、后台逐页解析、解析预览、失败重试、适用设备、新文件版本及历史版本列表、建索引、发布、停用。维修案例从已经验收完成的工单提取真实故障与措施，由用户确认保存为草稿，再索引和发布。
- MySQL先筛选权限和当前有效发布版本，向量与关键词混合检索后回MySQL复核，生成完成后再次复核。最多6个片段，拒绝未知引用；引用展示片段、原PDF页图和原文。案例引用可穿透原维修工单，不伪造PDF。
- 自然语言指标通过已有指标目录和统计Service取数，返回图表及穿透入口，不执行模型生成的SQL。没有停机/运行分母时拒绝把报修数量称为故障率。历史仅存查询摘要，重新查询取得最新图表。
- 报修可用文字、照片辅助形成草稿；处理工单可整理维修记录或获取排查建议。语音目前支持上传PCM WAV转写。用户明确采用后才填入原表单，不自动提交工单、登记工时、领料或改库存。
- AI设置包含文本/向量/视觉/语音模型、加密密钥、估算价格、月度硬预算及调用记录。记录保留用途、模型、耗时、用量、估算费用和结果状态，不额外保存提示词、密钥、照片或音频。

| 对象 | 关系及主要约束 | 主要查询与索引 |

| AI设置/月度用量/调用 | 租户设置乐观锁；租户+账期唯一；价格与费用DECIMAL(18,6)，人民币；Token为BIGINT；调用状态独立字段 | 租户调用按开始时间分页，过期RUNNING恢复 |

正文TEXT用于自然语言，不承载关联或计时。核心数据没有通用JSON字段；模型HTTP报文和前端图表配置不作为核心关系存储。原PDF与MySQL为事实来源，Qdrant可重建，只存向量及租户、公司、版本标识，不保存正文。

文件先写受控租户目录，数据库创建失败清理新文件；页面/片段原子提交；解析和模型请求不占用业务事务。后台任务每10秒扫描，租约和尝试次数处理重启恢复。索引失败可重新排队，解析失败可直接重试，需OCR页面配置OCR后上传替换版本。发布需解析和当前模型索引就绪，通过row_version比较更新。修改适用范围撤下发布指针，必须重新发布。

预算先锁租户设置及账期行，检查剩余额度并预占，再发HTTP。成功按供应商返回Token估算，未知结果按保守预占计费；旧RUNNING在后续调用前恢复。完整响应限定60秒和2MB。中断本地请求不能保证供应商停止生成或停止计费。

## 本地运行与配置

1. 启动MySQL、后端和前端；知识库菜单为`/#/knowledge`，模型配置为`/#/ai-settings`。
2. Windows开发环境执行`equipment-ledger/scripts/start-local-qdrant.ps1`。脚本从官方发行页下载固定1.20.0并核验SHA256，仅监听127.0.0.1:6333/6334，数据保存在被Git忽略的.local-runtime目录。正式部署需按运维环境配置持久卷、认证、备份与网络隔离。
3. AI设置选择同一区域百炼业务空间的HTTPS兼容接口，填入有效模型标识、密钥和供应商当前价格/月度预算后启用。密钥由既有NotificationSecret加密，部署端需稳定保存`EAM_NOTIFICATION_SECRET_KEY`，更换该主密钥前必须制定密文迁移方案。前端不返回保存后的密钥。
4. 向量模型变更后应重建索引并重新发布，禁止混用模型向量。上传PDF最大50MB/500页；先等待解析，再设置通用/适用设备、建立索引、发布。只上传不参与问答。
5. 可选本地OCR：配置`eam.ai.ocr-enabled=true`、`eam.ai.tesseract-path`与`eam.ai.ocr-languages`，安装Tesseract及对应语言包。未启用时扫描页标记NEEDS_OCR，不能当作可用文字发布。
6. 为普通账号明确分配知识库查看及公司范围；上传/发布/停用、AI设置分别授权。本轮只给既有系统管理员角色初始化新管理权限。

本机业务库迁移前已备份到`.local-runtime/backups/before-ai-20261028.sql`，V108—V115应用成功，无历史业务回填，无测试资料写入业务知识库。回退应用保留新增表和文件，不通过删除表清理用户资料。历史备份用于人工恢复核对，不能直接覆盖运行中的后续业务。
