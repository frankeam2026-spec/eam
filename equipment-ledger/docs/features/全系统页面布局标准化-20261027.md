# 全系统页面布局标准化（2026-10-27）

依据：用户要求保留content的上、左8px外围间距，并将统一布局推广至全系统。适用UI-35、UI-36及新确认的UI-111。

## 实现

- WorkspaceLayout统一使用AppWorkspacePage提供四周8px、可用高度及定位容器，所有路由页面自动接入。content不再重复提供外围padding。
- 顶栏高度只在公共层定义；页面按父容器100%高度布局，移除分别扣54px/56px的计算，以及阻碍较矮窗口的页面最小高度。
- 库存列表底栏使用42px公共尺寸，点巡检、位置、基础数据及标签列表同步；AppBusinessTable、分页与表单底栏继续复用。
- 设备完整编辑遮罩与设备历史相对工作区定位，移除硬编码侧栏宽度；普通弹窗、字段内部留白和全屏画布保持原语义。
- 保留本次开始时WorkflowPage中用户将背景声明注释掉的修改。没有修改业务接口、数据库、用户密码、权限或库存逻辑。

## 验证记录

- 前端36个测试文件、100项用例全部通过（layout-tests-limited.log）；首次与服务启动及构建同时运行时10项超时，降低并发至2后完整重跑通过，没有修改用例或放宽超时。
- 类型检查、生产构建通过；仅有已有的大包体积提示。没有后端代码变更，本轮未重复执行后端业务回归。
- 实际浏览器验证库存物料／仓库／库位、入库、领料、出库、库存查询各页签、退料／调拨／盘点／期初／纠正，以及台账、维修、保养、点巡检、用户、角色、组织、位置、基础数据、工作流、配置与模板页面的工作区边界。
- 1280×720及1920×1080：导航展开时内容起点为(184,62)，即侧栏176px与顶栏54px外再留8px；收起侧栏后内容左边为72px，即64px加8px。页面没有额外纵向滚动。
- 入库一条记录时分页仍位于列表底部，底栏42px；点巡检、位置、基础数据、标签底栏复查同为42px。设备列表有12条记录时可见表格与固定底栏分离。
- 设备登记、设备详情、日常／周期计划编辑、从保养列表进入的保养新增、领料及入库新增的外框与底部操作栏验证通过；临时新增页没有保存。
- 设计器内部全屏、各详情所有折叠区和全部业务数据组合未逐一穷举；卡片内部字段留白不属于本轮统一外围间距的范围。
