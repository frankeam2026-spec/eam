# 列表筛选器简化（2026-10-15）

## 实施

- 公共 AdvancedFilterDrawer 统一按字段类型渲染，不提供匹配方式、为空或不为空入口。
- 按用户后续确认，取消字段折叠，所有条件直接展示；保留字段搜索、滚动和已设置提示。
- 文本包含且忽略大小写；选项可搜索多选并折叠标签；日期单个区间；数值支持单边范围。
- 树形保留所选节点 ID，按页面提供的树解析下级并去重，查询使用原字段值映射；标签只显示所选节点。接口仍执行既有授权范围。
- 区间错误使用 AppFormField / ElFormItem 原生反馈；错误修正清除，未应用草稿取消或点遮罩丢弃。
- 本地筛选、维修 SQL 筛选及出库／业务扩展列表范围匹配同步日期结束日规则；保留程序调用的精确匹配及旧操作符接口兼容。
- 范围是已有公共抽屉的调用页面；未新增简单配置页面筛选器，未修改快捷搜索、列筛选或权限口径。

## 验证

- 前端生产构建、TypeScript 检查通过。
- `node scripts/test-advanced-filters.mjs`：文本大小写、多选或／字段且、数值单边与反向错误、日期当天末尾及次日排除、树形下级／去重／回填／标签、旧条件兼容通过。
- `AdvancedFiltersTest`、`RepairQueryServiceTest`：SQL 参数化树形多选、日期排他上界、数值边界、精确匹配兼容与字段白名单、文本通配符字面量及已有维修查询用例。
- 台账浏览器 1280×720：条件默认直接展示，文本+多状态应用得到三条结果；选择 A车间得到其下级工位八条设备；金额逆序错误就近显示且修正清除；取消和遮罩关闭均不应用草稿，再打开恢复已应用值。
