# 出库打印实用版

实施日期：2026-10-16

## 入口与范围

- 系统管理 → 打印模板：新增、复制、编辑、删除、启停，配置公司或公共模板、默认模板。
- 库存管理 → 出库管理：列表及已保存单据详情提供打印入口；有未保存改动时先保存。
- 系统提供只读标准出库单模板，用户复制后配置；模板数量为零时仍可打印。
- 固定内容分区，支持PNG/JPG Logo、标题、A4/A5/自定义空白多联纸尺寸、方向、字号、基本信息字段、明细字段与顺序、比例列宽、签字栏和说明。
- 出库单号、所属公司、状态固定显示；料号、名称和数量不可移除。多来源出库强制保留来源分组信息。
- 后端PDFBox沿用已有网格PDF引擎；前端公共AppPdfPreview使用PDF.js，支持逐页、适合页宽及整页查看。打印图像来自留底PDF，下载保留矢量PDF原件。

## 数据及权限

- V55新增eam_print_template、eam_print_job；正式PDF、模板配置和单据快照在同一事务写入数据库，不影响库存。
- 模板使用乐观版本、同公司默认模板唯一约束；公共模板维护需全部范围，公司模板按角色公司范围控制。
- 出库打印需要inventoryOutbound的查看及打印权限，并逐单校验仓库范围。带金额模板、原PDF下载和记录均校验查看金额权限。
- 内置模板不显示成本。成本来自原出库分配；币种来自成本层，按币种分别合计。
- 预览不产生留底记录。点击打印或下载才生成留底；留底表示文件已生成，不代表物理打印成功或打印份数。
- 请求键与内容绑定、预览指纹校验，重复提交返回原记录。单据或模板变化必须重新预览。
- 原PDF保留独立于模板更新、停用及删除；记录页显示最近100条，数据库保留全部。
- 默认示例管理员角色新增权限；其他角色需管理员明确授权，不自动扩权。
