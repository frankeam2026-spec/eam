# 业务字段配置与拖拽表单

日期：2026-10-16；字段内选项方案已按用户后续要求调整。首期对象：设备台账、维修报修。入口：系统管理 → 业务配置。

## 使用方式

1. 选择设备台账或维修报修。
2. 从左侧控件区拖入单个“扩展信息”画布，也可以点击控件添加。
3. 右侧属性栏修改名称、必填、启用和字段占宽；完整校验、默认值、列表／筛选／导出开关和联动在“更多设置与联动”中维护。
4. 布局支持 1～4 列；字段可跨 1～当前列数。表单宽度可以填满容器，或限定最大宽度 480～1920px。宽度不会超出承载容器。
5. 已有字段通过拖拽改变顺序，另提供上移、下移作为非拖拽操作。
6. 保存草稿后不影响业务录入，发布后实际表单生效。历史版本先恢复为草稿，再发布。布局变更不会更换字段 ID。
7. 单选、多选字段直接在右侧添加、改名、排序和启停选项；未发布选项可删除，已发布选项保留 ID 并可停用。选项跟随字段草稿／发布，不再提供“选项字典”页签。

支持单行文本、长文本、数值、日期、日期时间、单选、多选、是非、系统用户、部门。图片中地理定位、地址、附件等仅作为参考，本期未增加这些新的字段类型。核心系统字段不参与拖拽，自定义字段统一追加到原有表单末尾的“扩展信息”。

## 实现结构

- `BusinessFormDesigner.vue`：控件区、拖拽布局、属性栏、列数及占宽设置。
- `BusinessFields.vue`：实际动态表单、只读展示、显隐／必填联动、默认值和错误定位。统一显示于原有表单末尾，不移动系统字段。
- `BusinessFieldInput.vue` / `BusinessReferencePicker.vue`：Element Plus 控件及服务端分页选择器；关联对象保存 ID 和名称快照。
- `ExportFieldsDialog.vue`：设备、维修选择导出字段，导出能力独立于是否用于列表。
- 后端使用 Controller → Service → Repository。发布编排由 BusinessPublicationService 在事务内完成；BusinessRules、BusinessValueService、BusinessQueryService 统一负责规则、值、查询口径。
- V61 新建配置、不可变版本、字段身份、字典、选项、带类型的扩展值和操作记录表；布局保存为配置 JSON，不动态修改业务表结构。
- 业务主记录与扩展值原子保存；配置和业务记录均校验版本。用户、部门引用及筛选重新校验业务数据范围。空值与 0／false 分开处理。
- 列表批量读扩展值，设备列表使用服务端分页、条件及排序，导出复用同一条件。普通业务页面只读取已发布配置，无需业务配置菜单权限。
- 不新增绕开主业务的字段值写入接口。已发布字段身份及来源固定，停用字段与隐藏值保留。

## 未验证与限制

- 未逐一进行三种主题、所有控件键盘操作和浏览器兼容性验收；未进行十万级扩展值的压力测试。
- 复杂编辑最低桌面尺寸沿用 1024px；低于该尺寸不承诺完整设计体验。
- 维修计划自动生成、异常转报修等其他创建入口，本期没有增加扩展字段录入区。若为维修报修发布了无默认值的必填字段，这些入口仍会受到统一服务端必填校验，需后续接入同一录入协议；不通过隐藏豁免绕过校验。
- 本期不支持脚本、嵌套联动、任意绝对定位、字段级角色保密、打印模板和首页指标扩展。显隐用于表单布局，不是权限隔离。


## 后续调整：字段内维护选项（2026-10-16）

- 移除“业务字段／选项字典”切换和独立字典管理表单、操作函数、写入接口与相关无调用代码。旧字典管理路由明确返回 410，提示到字段中维护。
- `BusinessOptionsEditor` 在设计器右侧及字段完整设置中复用，提供名称、上下移动、启用／停用和草稿选项删除。选项最多200个，名称不允许空或重复。
- 新单选、多选字段的选项属于当前字段，使用稳定 UUID；实际录入使用 Element Plus 可搜索单选／多选框。联动规则读取当前草稿的选项，筛选和服务端校验读取已发布选项。
- 选项随字段配置版本发布。修改草稿不会提前影响录入，服务端拒绝新选停用项、伪造或其他字段选项 ID，以及删除已发布选项。
- 恢复历史版本时，后来发布过的选项保留并停用，保证历史记录关联不丢失。
- 已有字典来源的定义在读取时兼容为字段内选项；不改写历史版本原文或业务记录 ID，旧表仅为历史兼容保留，无新字典管理功能。原基础数据来源字段保持原有基础数据关联。
- 本轮后端与前端构建、类型检查通过；隔离环境真实认证通过 `verify-business-options.py` 的16项验收。浏览器验证拖入单选、右侧输入选项、上下排序、草稿保存和发布。截图：[字段内选项](../screenshots/业务配置-字段内选项.png)。
- 原33项字典接口验收脚本已调整为字段内选项流程并检查 Python 语法，本轮没有再次完整执行原51项场景或全部104项单元测试；上文结果为调整前的验证记录。

- 导出按 exportable 配置包含扩展字段，不要求该字段同时允许列表展示；扩展值显示名称快照。
