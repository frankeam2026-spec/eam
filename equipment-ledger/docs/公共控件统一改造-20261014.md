# 公共控件统一改造记录

日期：2026-10-14

## 已实现

设备台账作为样板，统一前端常用控件和表格实现。覆盖设备、维修、保养、点巡检、库存、基础数据、组织、用户、角色、标签和首页配置等页面。

- 表格使用公共 `AppBusinessTable` 和原生 `ElTableColumn`；排序、选择列、固定列优先使用 ElTable。删除旧 `BusinessTableColumn` 封装。
- 公共表格支持行对象或 ID 的受控选择，保留跨页选择；树形台账使用独立选择。操作列固定右侧，宽度至少156px。
- 列筛选仍保留在原生表头插槽，限制控件宽度，避免空数据时列宽扩大。
- 列表工具栏、页签、搜索输入框接入公共组件；工具栏白底、按钮34px、间距统一。
- 按钮、输入、下拉、日期、复选框、数值、颜色、上传控件使用 Element Plus；公共 `AppFilePicker` 保留原上传接口，提供 File[] 回调。
- 弹窗布局修正为视口内滚动，分页不再脱离选择弹窗；公共弹窗底部按钮居中、间距16px。
- 维修、用户管理和标签提示使用 Element Plus 消息或提示组件，明确区分成功和错误。
- 清理影响组件内部输入框的旧 CSS，补充控件样式导入。
- 更新 UI 规范和前端实施约定；增加控件静态检查，防止重新引入手写普通控件和旧列封装。

公共组件处理视觉和交互共性，各页面保留自身业务数据、事件和权限判断。打印画布和角色权限矩阵的业务布局保留。

## 已验证

- `npm run build`：TypeScript 检查及 Vite 构建通过。
- `npm run check:controls`：77个 Vue 组件通过，无手写普通表单控件及旧列封装。
- `npm run check:tables`：30个组件中的65个表格通过；原生 HTML 表格限打印画布和权限矩阵。
- `npm run check:icons`：通过。
- `git diff --check`：通过。
- 浏览器查看22个主要入口：未出现 Vite 错误遮罩，主内容区域未出现页面级横向溢出；有表格的入口表头为13px。
- 设备台账：列筛选、空结果和重置、树形父行独立勾选、批量菜单入口、分页；编辑页必填错误位于控件下方，没有重复成功提示。
- 用户列表：勾选后批量操作计数变化；编辑弹窗的已有值回填和布局正常。
- 出库页：默认出库列表、工具栏；未保存草稿的仓库选择、物料弹窗库存数量、多选计数、确认回填、取消流程。
- 设备台账在窄视口、1280×720和1440×900查看；出库编辑及用户弹窗在1280×720查看。最终设备台账刷新后无新增控制台错误。

以上浏览器检查未保存业务单据，仅废弃检查中创建的未保存内容。

## 保留与限制

- 个别业务专用弹层仍保留原布局容器，其内部普通控件已使用 Element Plus；本次不是所有表单的重新设计。
- 其他模块的字段级校验没有在本次全部改造成 ElForm；设备台账保持作为后续校验样板。
- ElUpload 没有公共打开文件选择器的方法，公共文件选择组件仅在此处调用其内部文件输入框。
- 树形列表单行选择按独立选择实现；原生全选的子级联动遵循当前 ElTable 行为。
- 构建和静态检查通过不代表业务验收完成。
