# 台账筛选弹窗样板（2026-10-15）

## 实施范围

仅设备台账启用公共筛选器的 `presentation="dialog"` 模式；其他调用方默认仍是 drawer。共用条件草稿、校验、控件及匹配逻辑，未复制筛选实现，未改接口、权限或数据库。

- 目标宽1280px，最大视口宽减48px；最高560px且不超过视口高减64px。
- 标题及底部按钮固定，只有条件主体滚动；顶部保留字段搜索。
- 通过分组与占列配置展示基本信息、组织与人员、采购与日期、其他属性；宽屏四列，按容器宽度降为三／二／一列。
- 台账不再追加“已设置”文字，已填条件标签使用主题色。日期、数值、树形规则保留。
- 应用后关闭弹窗；取消、叉号、遮罩关闭不应用草稿。

## 本轮记录

前端生产构建通过。浏览器人工查看1280×720（弹窗1232×560）、1440×900（1280×560），四列及固定底栏正常；自然窗口797×756下降为两列。恢复自然尺寸后保留页面。

实际操作：设备名称“数控”应用后返回三条设备；再打开回填正确；搜索“采购金额”只显示对应分组；逆向区间在输入框下报错并定位，窗口保持打开；取消丢弃错误草稿；清空并应用恢复12条。未写入业务数据。

未逐一重测所有类型的复杂组合、全部主题及其他页面；本轮未运行自动测试。推广需等待台账样板确认。
