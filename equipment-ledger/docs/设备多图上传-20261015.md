# 设备图片支持多张

- 设备编辑：Element Plus多文件选择，按选择顺序上传，缩略图逐张预览／移除，可将某张设为首图；单张沿用20MB、PNG/JPG/GIF规则。上传结束后随设备保存，未保存不改变设备图片关联。
- 接口增加images数组（文件ID和名称）；服务端校验图片类型、租户与文件读取权限并去重，以文件记录中的名称为准。
- V48新增images_json并迁移原image_file_id；原imageFileId/imageName继续表示首图，使既有列表和其他引用兼容。设备履历支持全部图片预览。
- 文件授权查询同时识别多图关联，非首图也按设备数据权限读取。
- 前端类型检查及构建通过，后端打包通过（skipTests）；已查看上传区域布局。未运行测试套件，未实际上传多张并保存设备进行端到端验收。
