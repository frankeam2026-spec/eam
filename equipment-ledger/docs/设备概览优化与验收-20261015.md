# 设备概览优化与验收

日期：2026-10-15。范围为设备档案概览、必要顶栏、动态页签及关联内容跳转；页面保持只读。

后续调整：概览仅展示并预览首张设备图片，移除图片数量角标；二维码改为身份信息右侧常驻展示，移除二维码按钮及浮层。基本信息中的多图展示保留。下方多图切换、二维码浮层的检查记录属于本次调整前的验收。

## 已实现

- 顶栏显示设备名称、编号、设备状态及使用状态，状态提供文字提示区分含义。
- 设备身份区使用首图约120px缩略图，支持所有图片预览；无图沿用公共设备占位图。展示型号、分类、品牌、部门全路径、位置及多位负责人，长内容可悬浮查看。
- 二维码收纳至点击浮层，展示设备编号及名称，不占用大块常驻空间。
- 四项紧凑数量摘要，可筛选维修、保养、点巡检及异常；无权限显示说明，不伪装为0，也不渲染灰色操作按钮。
- 当前事项默认5条，支持原区域展开完整列表和服务端分页；超期优先、创建时间倒序，缺截止时间不推断超期。
- 巡检已审核、过期作废等结束状态不再计入当前未完成任务；完整动态仍保留这些历史事件。
- 主栏／侧栏约2∶1，侧栏为最近5条在用备件和子设备／BOM／文件入口；数量按记录统计，不混合不同物料数量。
- 最近动态展示最新5条；完整动态使用独立页签、Element Plus时间轴、类型筛选、最新／最早排序及分页。
- 返回原业务详情、刷新时，按当前用户及设备恢复页签、当前事项筛选及展开状态、动态类型与排序、分页及每个页签的滚动位置。
- 概览、当前事项及事件独立处理请求状态、失败与重试，并防止设备切换或卸载后的迟到响应覆盖界面。
- 纠正原有档案明细表未绑定行数据的问题，使备件及关联资料入口能展示已加载记录。

## 实现说明

- 扩展 `GET /api/v1/equipment/{id}/overview`：授权数量、模块可访问状态、最多5条任务／异常／在用备件预览。
- 新增 `GET /api/v1/equipment/{id}/attention?kind=all&page=1&size=10`：当前事项分页，类型白名单为all、repair、maintenance、inspection、anomaly。
- 事件接口增加sort=asc/desc，旧调用默认asc保持兼容；概览显式请求desc及5条。
- 继续复用维修、保养、巡检和异常的现有授权判断，数量、预览和完整列表使用同一来源。支持当前用户作为任务参与人的已有访问口径。
- 概览在用备件复用设备履历查询，包含旧备件及库存安装记录，避免两个入口使用不同来源。
- 新增明确的前端数据类型及后端当前事项DTO；没有新增数据库表或迁移，没有修改库存或任务流转规则。
- 父页面header样式限定在档案顶栏，内部面板不再继承48px高度和边线。样式限定在设备档案，不推广其他详情页。

## 已验证

### 构建与自动检查

- 前端类型检查及生产构建通过。
- 后端打包通过；8项相关单元测试通过，覆盖：截止日包含当天、无截止时间、预览上限与完整总数、分页不重复、任务参与访问、越权排除、三类任务及异常分开统计、已完成／已作废排除、排序兼容、非法参数与跨租户拒绝、在用备件预览。
- 对本地12台设备执行194项只读API检查：各类数量／预览／分页一致，在用备件与履历一致，最新动态倒序、旧接口默认正序，非法参数拒绝。脚本 `scripts/verify-equipment-overview.py` 不写业务数据。
- 检查期间后端健康为UP，无新增数据库迁移。

### 实际浏览器检查

- 1440×900、1280×720均保持两栏，页面及档案正文无横向溢出。
- 使用有6项未完成保养的设备验证：概览仅5条，摘要筛选与展开后6条一致，原区域出现分页。
- 使用无未完成任务、无动态的复制设备检查紧凑空态；其2张实际设备图片可打开、切换和关闭。
- 二维码浮层图片成功加载；二维码未永久占据身份区。
- 动态最新／最早排序、异常类型筛选、刷新后的类型与排序恢复正常。
- 从最近动态进入真实异常详情，浏览器返回后保养筛选、展开状态和概览滚动位置恢复（观察恢复至508px）。
- 关联资料可切换基本信息并定位BOM区域；备件入口保留只读查看。

## 未验证与限制

- 未在本轮重新执行所有真实账号、角色及跨部门权限矩阵；权限分支有单元验证，实际只读API检查使用当前本地开发身份。
- 当前本地设备在用备件为空；非空预览与排序通过单元测试，尚未以本地真实安装记录完整重放UI。没有为了截图制造业务安装记录。
- 全部主题、极长文本、多负责人、多份资料同时存在的浏览器组合及大量历史事件性能未完整回归。
- 没有新增截止时间：本地部分保养任务原始截止时间为空，因此列表相应单元格留空，不显示错误的超期标记。
- 构建仍有既有首页分析分块大于500kB的提示，不属于此次设备概览新增问题。
