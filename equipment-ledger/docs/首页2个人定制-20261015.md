# 首页2个人定制

## 范围

- 仅完善 `/home2`，保留原首页、模板管理及工作台。
- 使用现有发布的角色模板作为默认内容，转换为主栏／侧栏布局；合并待办、执行中、今日任务为“我的工作”。
- 添加、移除区块，拖动标题排序或跨栏移动，提供上移／下移按钮。我的工作固定属于主栏，其他区块可选位置。
- 可修改区块标题、显示条数（5/10/20）、受支持区块的业务范围、个人／授权团队范围；顶部指标可显隐。
- 执行类区块一种仅保留一份；分析区块支持按独立区块 ID 添加多份。保留1至12个区块；移除和恢复模板仅修改草稿，点击保存才写入。
- 底部使用公共 AppFormFooter，固定在页面内容区域底部；公共未保存保护及 ElForm/AppFormField 校验。

## 存储与权限

- 新增 GET/PUT `/api/v1/home/overview`，支持按模板加载／保存个人配置。
- V50 新建 `eam_home_overview_layout`，按租户、用户、模板独立保存，版本字段防止并发覆盖；不写原首页的 `eam_home_layout`。
- 沿用 workspace 菜单权限与现有角色模板适用性；服务端校验区块目录、团队权限、配置范围、位置、重复区块、版本。
- 保留个人布局，角色模板有新版时提示；恢复采用最新已发布角色模板。
- 最近一次保存的、仍有权限的模板作为下次进入首页2的选择。
- 任务、快捷入口和其他区块继续使用现有权限接口；不新增跨公司可见范围。
