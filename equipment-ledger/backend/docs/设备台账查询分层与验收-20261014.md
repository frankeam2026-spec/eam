# 设备台账查询分层与验收

日期：2026-10-14。

## 已确认范围

用户确认先改造影响较小的设备台账查询部分；其他业务模块不改造。本轮不进行数据库迁移，不调整业务规则和UI。

## 查询分层

调用链：设备查询Controller → EquipmentQueryService → EquipmentQueryRepository → MyBatis/JdbcTemplate → MySQL。

- `equipment/controller/EquipmentQueryController`：只负责HTTP参数、响应封装和二维码响应头。
- `equipment/service/EquipmentQueryService`：权限校验、可选部门范围、组织导航计算、只读关联回填、履历汇总及二维码生成；不直接引用Mapper或JdbcTemplate，不编写SQL。
- `equipment/repository/EquipmentQueryRepository`：列表条件、白名单排序、分页、设备/组织/基础数据读取、负责人、子设备、BOM、履历和在用备件查询。接收由Service提供的已有权限范围过滤器，不自行决定业务权限。
- `equipment/dto`：列表查询、分页、设备详情、负责人、组织节点、选择选项和履历响应。ID、金额、日期字符串和空值形式保留原契约。
- 设备历史明细和关联历史快照暂保留动态明细结构，避免本轮改变兼容数据字段。

## 已迁移接口

| 接口 | 职责 |
|---|---|
| GET /api/v1/equipment | 列表、筛选、排序、分页 |
| GET /api/v1/equipment/{id} | 详情 |
| GET /api/v1/equipment/{id}/qrcode | 设备编号二维码 |
| GET /api/v1/equipment/navigation-tree | 可见公司部门树 |
| GET /api/v1/equipment/batch-options | 按新增/编辑权限提供选择选项 |
| GET /api/v1/equipment/{id}/history | 履历、BOM及在用备件展示 |

## 明确保留的部分

- 现有EquipmentController保留创建、更新、删除、批量操作及其事务、编号、数据校验和加锁顺序；只有返回详情的组装委托查询Service。
- 子设备候选和BOM物料候选仍由原EquipmentRelations提供，附件仍沿用EquipmentFileController/EquipmentFiles；本轮未迁移。
- Equipment实体、EquipmentMapper、NumberCounterMapper保留原包名：其他模块已经引用，不为目录调整修改这些调用方。
- 保存、删除、批量操作尚未完成业务Service化。因此本次为查询样板，不代表设备模块已经全部分层。
- 未引入微服务、DDD、框架升级、新ORM或数据库结构变更。
