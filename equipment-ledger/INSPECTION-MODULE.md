# 点巡检模块（网页端）

## 入口与页面

一级菜单“点巡检管理”包含：点巡检标准、日常点检计划、日常点检任务、周期巡检计划、周期巡检任务。

- 标准项目采用行内编辑表格，不设置模块列；支持数值范围、可选项、正常选项、必填、图片和参考附件，以及批量设置类型和选项。
- 巡检类型从标准页面维护；预置日、周、月、季、年，可维护名称、周期和单位。
- 计划设备采用行内编辑；通过标准与项目选择弹窗跨标准选择项目。默认展示设备关联的标准，可切换全部标准。
- 周期计划支持设备路线排序、巡检周期、提前生成、有效时长、人员及审核设置。
- 日常计划支持班次及跨夜班、按周/月休息日、节假日、指定负责人、任何人点检、排班表，设备与排班 CSV 导入。

## 自动生成

保存计划时执行一次生成；后台每分钟扫描计划。周期任务依据下次巡检时间和提前生成时长（时、日、周、月）生成，并推进周期游标。周期按计划锚点计算，避免月底日期累积漂移。

日常任务按设备、日期及班次生成，跳过休息日及节假日；默认在班次开始时生成。配置提前生成或提前提醒时，为发出开始提醒，提前创建“未开始”任务，到班次开始才允许执行。未排班时可配置跳过。

任务使用租户、计划、设备、班次、计划开始时间的唯一约束防止重复生成。已经生成的任务保存计划与项目快照；后续修改计划不会改写历史任务。

## 执行、审核和提醒

任务支持领取执行、设备编号校验、暂存、提交、挂起、恢复、转派、作废和删除。多人为候选负责人时，服务端通过事务锁确保只有一人领取执行。

执行项目采用表格，支持照片上传、异常措施、仅异常填报、随机必拍项目、跳过设备及原因；服务端校验结果选项、数值范围、必填、图片要求和设备校验规则。

审核支持无需审核、整机审核、逐项审核，结果通过或打回，附说明和附件；支持批量审核。无需审核任务提交完成或审核通过后，生成设备的巡检履历。

顶部提醒与工作台待办接入点巡检：待执行、待处理、待审核、审核打回，以及开始/过期提醒。任务列表提供“我的待执行”“我的待审核”入口。

任务操作记录包含操作人、时间、动作和说明；详情右侧按时间正序展示点巡检时间轴。

## UI 与权限

沿用系统规范：蓝色主题，列表表头 13px 加粗、正文 13px，操作列固定，分页位于卡片底部左侧，设置列与导出在右侧，任务列表支持列筛选和筛选器；表单底部按钮居中且保留间距。

定义维护、任务查看、审核、转派、删除、导出均在服务端校验租户和对应权限范围。被指派的执行人和审核人可以访问自己的任务。导出从后端重新获取并校验指定记录，不信任浏览器中的记录内容。

## 2026-10-10 布局与时间单位调整

- 提前生成、有效时长、开始前提醒、过期前提醒统一支持时/日/周/月，持久化单位；月按自然月加减计算。旧记录没有单位时按小时处理，任务快照保持不变。

- 任务详情的挂起、恢复、转派、作废、删除统一在右上角；执行、保存、提交、审核在底部居中；检查项目表格合并异常处理和说明，参考资料在方法列展开。
- 全系统现有编辑页与详情页统一使用 AppBackButton，返回样式以设备详情为基准。
