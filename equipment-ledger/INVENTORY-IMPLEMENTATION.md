# 物料与库存：第一阶段实现与使用说明

更新：2026-10-11。设计依据：[物料与库存设计 v0.1](../物料与库存设计-v0.1.md)。

## 本轮调整

- 物料标识统一为料号；物料分类在基础数据独立维护，支持树形选择，单位选择基础数据单位。既有值迁入字典，改名同步物料引用，使用中的单位和分类禁止删除。
- 库存菜单改为库存管理，导航支持菜单名称搜索；库位通过仓库行的“库位”入口维护。没有库位的仓库提供默认库位，多个库位需明确选择。
- 维修人可以从工单发起领料申请；提交后产生待出库事项。待出库列表支持单个和同仓库多申请出库，合并确认有统一单号并保留每张申请的出库分配。
- 出库预览会预留库存。取消预览不自动释放预留，可在申请详情释放；确认在一个事务中完成，任何一张失败时整组不扣库存。
- 保养、日常点检、周期巡检任务列表增加公司/部门树，节点来自授权可见任务及组织祖先路径。
- 列表操作列至少156px，已有三个操作的列表将第三个收入更多菜单；集团和公司统一三个框图标，存放地点的组织图标跟随主题。
- 修复空关联编号解析、仓库缺少默认库位及出库记录字段长度不足的问题。

“历史库存”指新库存模块接入前的记录，缺少公司、仓库、物料映射或成本时必须先初始化，不表示过期物料。

本轮未执行真实入库、合并出库交易或并发验收。

本文件记录已接入的代码与本地运行证据。构建及空页面加载不等于真实库存交易验收；没有伪造实际交易、并发或旧数据迁移的验收结果。

## 一、页面入口

一级菜单“库存”包含以下入口，保持原设备、维修、保养和点巡检页面。

| 入口 | 功能 |
| --- | --- |
| 物料档案 | 集团统一维护编码、名称、规格型号、单位、分类、用途、参考价、批次、有效期及分配规则；支持启停、查询和导出 |
| 仓库管理 / 库位管理 | 公司所属仓库、仓管、库位及默认 FIFO / FEFO 分配规则 |
| 入库管理 | 草稿、行内明细、不含税单价、费用分摊、税率、批次及日期；价格确定后确认；草稿删除 |
| 领料申请 | 关联维修 / 保养 / 点巡检任务；提交、自动预留、手选库位与批次、释放、部分发料、成本预览及确认；草稿删除 |
| 退料管理 | 关联原发料分配，退回已发未用数量，保留原批次、原成本与来源时间 |
| 调拨管理 | 同公司源仓调出、在途、目标仓接收；接收人员获得待办 |
| 盘点管理 | 建立基准，行内填写实盘数量，保存时记录观察账面数量，显示期间收发；确认差异形成盘盈 / 盘亏流水 |
| 期初与初始化 | 人工指定公司所属仓库、库位、物料和确定成本；可关联旧库存 ID；已有非批次库存通过初始化转换成批次库存，沿用成本与来源时间 |
| 单据纠正 | 关联入库、出库、退料、调拨、盘点或期初生效单据，记录原因并形成反向流水；阻止直接冲销已经使用、预留或发生后续变动的来源数量 |
| 库存查询 | 库存余额、成本明细、库存流水、在途库存；批次分布及日期查询、来源单据跳转、冻结 / 解冻与导出 |

列表采用统一的 13px 字号、加粗表头、固定操作列、表格内滚动及一体底栏。总数和分页靠左，设置列和导出图标靠右。单据使用全页编辑和居中底部按钮，日期使用 Element Plus 控件。

## 二、正常使用流程

1. 维护物料、公司所属仓库和库位。批次开关属于物料；有效期管理要求启用批次。
2. 保存入库或期初草稿，填写确定的不含税单价。可逐行填写费用，或先保存后按采购金额比例自动分摊费用，尾差落在最后一行。
3. 确认入库后形成余额、成本层、批次及入库流水。没有价格的草稿不能确认。
4. 执行维修、保养或点巡检任务时，在“任务用料”申请领料。任务类型和编号自动带入申请页面。
5. 仓管通过待办打开申请，自动预留或手选批次 / 库位，再预览成本分配并确认发料；可分次发料。
6. 任务执行人在“任务用料”记录消耗或安装。可安装物料记录设备、数量及来源；换下时填写去向。安装不再次扣库存。
7. 未用数量通过退料单关联原发料分配退回。设备履历展示新旧来源的在用备件及更换记录。

### 调拨、盘点和纠正

- 调拨只能选择同公司不同仓库；发出后为在途，接收后才计入目标仓。来源批次与成本不重新编号或重估。
- 盘点实盘数据先保存。保存时记录当时账面数量，确认时使用“实盘减观察账面”的差异，不覆盖期间后续收发。
- 生效单据保留，不能直接删除。纠正单核对来源成本层是否仍完整、是否被预留以及是否已有用料 / 安装 / 退料，再生成反向记账。
- 批次初始化属于追踪模式转换，不能通过普通冲销直接回退模式；后续数量问题用库存业务单据处理。

## 三、成本与库存一致性

- 金额使用服务端 BigDecimal，数量 / 单价最多六位小数，金额按人民币分处理；本阶段币种为 CNY。
- 库存成本是不含税采购金额加分摊费用；税率、税额和含税金额另存，不混入库存成本。
- 同批次可以有多个成本层。非批次物料也保留成本层，不展示内部无批次键。
- 自动分配采用物料规则优先、仓库规则兜底；FIFO 按原来源时间排序，FEFO 先有效期再来源时间。
- 排除冻结、过期、缺少必要有效期及停用物料 / 仓库 / 库位；不能消耗其他申请的预留。
- 发料最后一次承接成本层剩余金额；退料沿用原出库分配金额和成本来源。
- 余额、成本层、分配、单据状态、流水和待办在同一事务内提交；失败回滚。租户库存互斥行统一写锁顺序，初期优先保证一致性。
- 草稿使用版本号；发料预览有指纹，确认时重新核对；发料 / 用料有确认标识，单据确认按状态保持幂等。

## 四、任务、待办与历史数据

- 仓管待发料、目标仓待收货接入顶部待办中心；优先通知具有对应仓库权限的仓管，无有效仓管时通知有操作权限的人员。
- 提交领料、收发、调拨、退料、盘点、纠正、冻结及用料均保存操作记录。用料事件同时写入对应维修 / 保养 / 点巡检时间轴。
- 每 30 秒清理已结束或删除的来源任务预留，关闭申请和仓管待办；确认发料时还会即时检查任务状态。
- 旧库存保留原 ID、旧领用、安装及设备履历。初始化保存旧库存到物料 / 仓库 / 期初行的映射，完成后原库存数量置零。
- 未明确归属和成本的旧库存保留待初始化，不默认为零成本。已换下旧件只记去向，不自动入库。
- 旧库存直接新增、旧简化领料和出库入口已停用，防止绕过成本与批次；已有旧发料的安装 / 换下记录仍可使用。

## 五、权限

权限拆到物料、仓库、入库、领料、退料、调拨、盘点、期初、纠正和查询子菜单。

- 查看金额、编辑参考价、入库确认、出库确认、冲销分别授权。
- 仓库业务支持全部、本公司、指定多个仓库的数据范围；物料按集团统一维护。
- 接口验证租户、单据所属仓库及对应操作。金额查看和导出范围逐仓库核对，不能因为另一仓库有权限而读取当前仓库金额。
- 角色权限页面支持选仓库，不强迫改用部门授权。
- 调拨源仓负责调出、目标仓负责接收；具备任一相关仓库查看权限可查看关联调拨单。

## 七、验证边界与后续独立范围

目前本地库存及旧库存为空。已核对构建、数据库迁移、服务启动、查询与选择数据接口，以及页面显示；尚未用真实交易覆盖多价同批、成本尾差、并发、完整退调盘冲和旧记录迁移。不能把这些场景标为验收通过。

批次初始化当前用于已有非批次库存启用批次，必须一次覆盖该物料全部仓库库存，且没有未完成单据、预留或在途。跨公司调拨、回收审批入库、工具借还、平均成本、标准成本与后续价格调整，按已确定设计另行开展。
